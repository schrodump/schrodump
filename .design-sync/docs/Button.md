The one action control. `primary` is the single main action on a screen (amber fill); `accent` an amber-tinted secondary; `secondary`, `quiet`, `ghost` descend in emphasis; `danger` is destructive and never amber. The ONLY way to disable it is `disabledReason` — the reason renders beside the button as `BLOCKED — …`, so a disabled control always says why.
